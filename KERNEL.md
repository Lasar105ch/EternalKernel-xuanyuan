# EternalKernel — xuanyuan

Experimental kernel development for Xiaomi 15 Ultra.

Stock baseline: Linux 6.6.118, android15-8, 4 KiB pages, Clang r510928, build ID 16143355, commit prefix 0908354dac1b.

Target firmware: OS4.0.8.0.XOAEUXM. Target ROM: LineageOS 24.0.

First milestone: reproduce the stock GKI baseline, verify KMI and module compatibility, and preserve a stock recovery path. No experimental build is approved for flashing until validated.
